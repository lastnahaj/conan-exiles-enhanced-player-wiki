# Building

Start with the job you need to do: placing a piece, supplying a recipe, sorting materials, or choosing a building set.

## Choose a building workflow

| Your task | Start with | What you will do |
| --- | --- | --- |
| Place or orient a piece | [Building Placement](./lbpr.md) | Read preview arrows, placement feedback, and available building information. |
| Supply crafting materials | [Unlock Plus](./unlock-plus.md) | Pull ingredients for a recipe from supported nearby storage. |
| Clear carried materials | [Unlock Plus](./unlock-plus.md#choose-the-right-transfer) | Choose the correct storage transfer and retained amounts. |
| Organize mixed loot | [WoV sorting](../crafting/wov-storage-resources.md#dump-chest-workflow) | Route loot into the destination categories you have placed. |
| Add a building set or decoration | [Highmane crafting and decor](../combat/highmanes/crafting-building.md) | Check the relevant knowledge, recipe, and bench. |
| Browse structures and placeables | [ExilesExtreme catalog](../combat/exiles-extreme.md) | Search the local catalog, then inspect the item's current recipe. |

## Prepare before building

1. Check the recipe for the piece or station you intend to place.
2. Gather or pull the listed materials.
3. Inspect orientation and placement feedback before confirming.
4. Check access and storage behavior before using the result for shared clan supplies.

A placement helper changes how construction works; it does not establish permission to build in a restricted area. Use the game's placement feedback and the server's published rules.
