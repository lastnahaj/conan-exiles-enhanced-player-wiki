# Building Placement


Less Building Placement Restrictions expands the placement options and visual helpers available to
builders. Nearly every major capability is configurable, so this page separates documented tools
from the restrictions actually active on this server.

## Documented player-facing tools

- Placement-blocker rules can be relaxed or retained by server policy.
- Overlap and placement exceptions can permit arrangements rejected by the base game.
- Follower placement has its own group of placement helpers.
- Green directional arrows make piece orientation easier to read, with an optional base-game arrow
  display for players.
- Personal preview choices can switch between ghost-style and solid-object placement previews.
- The restored **Tab** shortcut can show building health, decay, and stability information while
  building.

## What this does not mean

The mod is capable of allowing construction in normally restricted areas, but that capability is
off by default in the source and can be limited or disabled. It is not evidence that building in an
NPC camp, dungeon, cave, or other blocked area is permitted here. Only observed placement behavior
and supplied server rules can establish that.

Use the ordinary in-game placement feedback as the final answer when a piece is rejected. A future
server-verified version of this guide can list which restrictions remain without exposing private
configuration.
