# Economy

Currency information, milestone rewards, bounties, and trading are separate systems. Start with the activity you are doing rather than assuming they share one reward or inventory.

## Find the right interface

| You want to… | Open or read |
| --- | --- |

## Organize currency and activity loot

1. Review the [WoV sorting destinations](../crafting/wov-storage-resources.md#sorting-destinations).
2. Place the destination chests for categories you use, such as Currency, Bounties, Gems, Keys, and Lore.
3. Deposit mixed loot through the Dump Chest workflow.
4. Open the corresponding destination chest to check the result.

For other storage-transfer actions, use [Unlock Plus](../building/unlock-plus.md#choose-the-right-transfer). Configure retained supplies before using a broad deposit action.

## Read a transaction before committing

Inspect the current merchant or reward interface for its inventory, requirements, and payout. The server's **5x rates** label does not establish an item price, exchange rate, or bounty payout.
