# Highmane's Arsenal


![Official Workshop gallery image for Highmane's Arsenal](/media/mods/highmanes-arsenal.png)

Highmane's Arsenal is a large content expansion with more than 2,000 documented items. This guide
incorporates the player-relevant feature map while keeping the catalog filtered to content a normal
player can actually obtain on this server.

## Start with the item you need

1. Choose the item category: equipment, accessory, crafting/decor, or companion.
2. Open the matching local guide in the catalog section below.
3. Learn the relevant Highmane knowledge group.
4. Inspect the matching universal-bench recipe.
5. Check the finished item's properties before treating its appearance as a sign of function.

Use the equipment and accessory guides for combat decisions. Use the crafting and building guide
for station flow and construction categories.

## Player-relevant feature map

| Area | What the current Enhanced source documents |
| --- | --- |
| Weapons | Hundreds of weapons, dozens of new movesets, and supporting item effects. |
| Armor and clothing | Functional armor sets with bonuses plus cosmetic clothing. |
| Accessories | Hundreds of standard appearance options and a separate infused group with combat effects. |
| Consumables | Poisons, buffs, utility items, and novelty effects. |
| Crafting | Recipes split across knowledge groups and four universal crafting benches. |
| Building | More than 500 decorations, customizable or clustered setups, foliage, and building-set additions. |
| Character appearance | Additional hairstyles and beard choices. |
| Companions | Pets, rideable mounts, and saddles. |

The source describes most ordinary recipes as using base-game resources with costs scaled by item
rarity. It also identifies optional crafting conversions, including craftable Eldarium and a route
from Keystone pieces to Fragments of Power. These are mod capabilities; the corresponding knowledge,
recipe, and station must be visible here before this wiki presents a player acquisition route.

## Building examples from the source

The current Workshop description names the Woodglass set and the Crypt reskin as examples of its
building additions. It also describes grounded decoration themes, base-game foliage, and
pre-decorated clusters. Their presence in the source does not establish server availability.

## Public catalog filter

An individual entry is published only after ordinary-player acquisition and behavior are verified.
Each record carries its source, category, route, station, requirements, effect, PvP notes, server
restrictions, verification date, and image provenance. Entries without a verified ordinary-player
acquisition path are excluded.
