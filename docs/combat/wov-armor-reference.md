# WoV Armor Stats — Legacy Reference

::: danger Historical values only
The armor guide itself was marked **NEED UPDATE** before Enhanced released. The table below is kept
locally so the old guide is not lost, but none of these armor values, bonuses, temperatures, routes,
or effects are asserted for the current server. Read the live Enhanced item panel before choosing
PvP gear.
:::

The older guide stated that bonuses and active effects belonged to individual pieces, so a full set
was not required. It also documented one Runeforged Armor Plating per piece in three qualities,
crafted at the Rune Forge. Current Enhanced behavior must be checked in game.

## Other player routes recorded by the old guide

- Valkyrian and Lava Legion armor came from Valkyrian Armor Crates associated with bosses or the
  old Bounty Board.
- Kaali and Shadow Twin armor were listed as old Bounty Board purchases.
- Elder armor was crafted at the Elder Weaponsmith's Bench with Shadow Twin Maria and rolled random
  armor and durability. The guide recorded 100–2,000 armor per piece, but also warned that the
  update at that time had disrupted Elder armor statistics and buffs.

Armor entries marked administrator-only in the old source are intentionally not reproduced here.
