# WoV Arsenals and Armor

![Official Enhanced Workshop weapon image for Wings Of Valhalla](/media/mods/wov-weapons.png)

## Fifteen weapon arsenals

The current Enhanced build contains fifteen arsenals with fourteen items in each family:

| Group | Arsenals |
| --- | --- |
| Ancient metals | Ancient Copper, Ancient Bronze, Ancient Iron, Ancient Steel, Ancient Silver |
| Natural materials | Nordic, Bone, Chitin Scale |
| Elemental and rare materials | Lysanthir, Unholy Ice, Pure Jade, Lava Stone, Urghat |
| Sacred and forged | Holy Serpent, Vanir Steel |

The current build also enables dual wielding for base-game swords.

### Legacy-era weapon-type reference

The Legacy-era guide cataloged bows, arrows, claws, daggers, great-axes, hammers, maces, spears,
swords, two-handed swords, war-axes, dual variants, and three shield sizes across the arsenals. The
Enhanced Workshop page confirms the arsenal count and family names, but the current crafting menu
is the authority for which of those older item types remain in each family.

## Random crafting quality

Crafted WoV gear can roll random affixes and quality tiers. Review the finished item before
equipping or discarding it; two crafts from the same family may not have identical properties.

## Armor families

| Family | Current Enhanced variants |
| --- | --- |
| **Valkyrian Armor** | Silver, Gold, Fallen, Desert, Jungle, Mountain, Lava |
| **Additional armor** | Lava Legion, Mythical Crystal, Infused Crystal |

Wings Of Valhalla Equipment supplies custom weapons and Mythical Crystal armor for the main mod.
Older VAM armor-stat tables are not reused for Enhanced values; read the current item panel for
armor, attributes, temperature resistance, and effects.
