# Highmane Pets & Mounts

The current Enhanced release adds pets, steeds, rideable mounts, and saddles to the companion
catalog.

## Check a companion in order

1. Find the visible recipe or acquisition route.
2. Identify whether the companion is a pet or rideable mount.
3. For a mount, read the saddle's compatibility information.
4. Inspect the live follower panel for current attributes and growth.
5. Check follower-group compatibility before combining it with other followers.

The model or name alone does not establish saddle compatibility or the active follower group.

## Before raising or equipping one

- Confirm that the recipe or acquisition path is visible to an ordinary player.
- Check whether the companion is a pet or a mount; only mounts use a supported saddle.
- Read the saddle panel for compatibility instead of assuming every Highmane saddle fits every
  steed.
- Use the live follower panel for current statistics and growth chances.
- Use [Better Thralls](../../followers/better-thralls.md) only for compatible group commands; some
  modded companions can use a different follower group.

Exact companion names, acquisition routes, saddle pairings, and statistics are not invented when
they are absent from the current public description.
