# Highmane Pets & Mounts

The current Enhanced source documents new pets, steeds, and saddles. This establishes the catalog
categories but not which companions are player-obtainable here.

Pets and mounts are published only with a confirmed ordinary-player acquisition route. Each entry
distinguishes its category, requirements, player-facing behavior, saddle needs, and any PvP or
server restriction.

No individual companion entry is published yet because availability has not been verified.
