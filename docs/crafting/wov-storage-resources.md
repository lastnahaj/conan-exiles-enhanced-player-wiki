# WoV Storage, Resources, and World

## Dump Chest workflow

The **Dump Chest** automatically routes deposited loot into specialized WoV sorting chests.

1. Open the construction hammer.
2. Go to **Decoration → Wings Of Valhalla**.
3. Place the Dump Chest and the specialized sorting chests you want to use.
4. Deposit mixed loot into the Dump Chest.
5. Retrieve the routed items from their destination chests.

## Sorting destinations

| | | | |
| --- | --- | --- | --- |
| Arrows | Bones | Bounties | Bricks |
| Currency | Dust | Dye | Food |
| Gems | Keys | Leather | Liquids |
| Lore | Ingots | Ore | Pets |
| Plants | Potions | Seeds | Wood |

You only need to place the destination categories you want the system to use.

## Tools and resources

The current Enhanced build includes **seven complete tool sets** and **fifteen new resource types**.
The resource nodes are found in the mine below the Player Market. Use a tool and resource recipe
visible in the Enhanced crafting interface for the current requirements and harvesting behavior.

## Player areas

| Area | Player use |
| --- | --- |
| **Player Market** | Central market area and access point for nearby WoV features. |
| **Portal Room** | Travel hub for configured destinations. |
| **Resource Mines** | Mining area containing the documented WoV resource nodes. |

## Torch bracelets and icons

![Official Enhanced Workshop image showing the six WoV torch bracelets](/media/mods/wov-torch-bracelets.png)

WoV includes six colored torch bracelets. The live build also replaces the icons used for all
potions and ingots, making those item categories easier to identify in inventories and sorting
chests.
