# Proximity Party

Proximity Party shows health bars for nearby clan members and followers. Players take priority
over followers when the display fills.

## Set up the display

1. Open the in-game console and run `dc proxyparty`.
2. Enable the display if needed.
3. Set a comfortable interface scale and detection range.
4. Choose how many bars to show, from **1 to 15**.
5. Hold **F1** with the published default binding to interact with and move the window.

## Choose the information you need

| Setting | Use it to |
| --- | --- |
| Interface scale | Make the bars readable without covering combat information. |
| Detection range | Adjust which nearby actors are considered for the display. |
| Bar count | Balance the number of visible actors against screen space. |
| Enable/disable | Hide the display when it is not useful. |

## If a follower bar is missing

The display prioritizes players over followers. Review the range and bar-count settings before
assuming a follower is missing from the game. If F1 does not free the pointer, check the binding
conflicts covered in [interface troubleshooting](../getting-started/mod-troubleshooting.md#f1-does-not-free-the-pointer).
