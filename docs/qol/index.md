# Quality of Life

Set up the interfaces you use most, then keep the controls reference nearby for less frequent tasks.

## Configure your screen

| Need | Guide | Published control |
| --- | --- | --- |
| Navigation and personal map markers | [Simple Minimap](./simple-minimap.md) | Hold **F1**; **Shift-click** on the full map for a marker. |
| Encounter damage and combat logs | [The Damage Meter](./damage-meter.md) | Hold **F1** for interaction. |
| Nearby clan and follower health bars | [Proximity Party](./proximity-party.md) | Run `dc proxyparty`; hold **F1** to move the display. |
| Armor, weapon, and follower appearance | [Fashionist](./fashionist.md) | Blue inventory control or `DataCmd Fashionist Config`. |
| Stack behavior | [Stacksize Plus](./stacksize-plus.md) | Move the affected stack between inventories to refresh changed settings. |
| Loaded mod names and versions | [Simple Modlist](./simple-modlist.md) | Open **ESC**. |

## A practical setup order

1. Position the minimap where you can read it comfortably.
2. Set the meter's scale and location for combat review.
3. Adjust the nearby health-bar display to suit the group information you need.
4. Save appearance settings after changing Fashionist options.

Bindings can differ from the published defaults. If F1 does not enable interaction, follow [binding and overlay troubleshooting](../getting-started/mod-troubleshooting.md#f1-does-not-free-the-pointer).

For travel-placeable guidance, see the [Mystical Travel Shelf](../travel/mystical-travel-shelf.md).
