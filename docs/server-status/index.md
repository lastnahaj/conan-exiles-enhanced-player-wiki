# Server Status

<ServerStatus />

Connect to `192.34.101.207:7785`. The status feed checks the server's public Steam query response
approximately every five minutes. Scheduling delays can occur. Responses older than 15 minutes are
marked out of date; an old response does not establish whether the server is currently online.
The player list appears when the server exposes it.
