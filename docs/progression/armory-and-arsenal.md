# Armory and Arsenal

**Source mod:** [Enhanced] Armory and Arsenal v1.2.9 (`3718199031`)

![Official Workshop image for Armory and Arsenal](/media/mods/armory-and-arsenal.png)

Armory and Arsenal is a connected progression, gear-building, follower, merchant, and endgame
system. Its current Enhanced Workshop documentation is summarized here so the player guide does not
depend on an external description.

## Open the installed-build guide

Open the player menu from its inventory button or press **Shift+V**. The menu includes the mod's
in-game guide and is the best reference for the exact build installed on the server.

## Character and gear systems

| System | Current Enhanced source documents |
| --- | --- |
| Skill development | Three skill trees and 36 perk runes. |
| Classes | Five classes, each with separate experience, perks, and ability bonuses. |
| Weapons | More than 700 craftable weapons, including custom-moveset options. |
| Armor | More than 350 armor pieces for gear building. |
| Gems | More than 400 collectable, equippable gems. |
| Accessories | 120 accessories with an enchanting interface. |
| Pets | 40 craftable pets. |

Those counts describe the mod's catalog, not what this server has made obtainable. Exact class
bonuses, skill requirements, recipes, gem effects, enchanting costs, and item statistics remain
unpublished until confirmed in the live player interface.

## Endgame and world content

The source describes eleven boss tiers with roughly sixty or more custom bosses, 38 named followers
to hunt and collect, placeable merchants that buy materials, enhanced tools, and recipes associated
with some named followers. Server-specific spawn locations, merchant inventories, prices, drops,
and encounter access are not inferred from those catalog facts.

## Utility and advanced progression

- The camera can be extended farther than the standard view when that feature is available.
- A documented grindstone workflow can change a weapon's scaling family, including weapons from
  the base game or other mods.
- Ascension is documented as a level-reset progression loop with bounded rewards rather than
  unlimited power.

All three features are modular. This wiki will add exact steps and values only after they are
visible to an ordinary player on this server.
