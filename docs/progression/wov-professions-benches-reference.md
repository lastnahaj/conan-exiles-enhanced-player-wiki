# WoV Professions & Benches — Legacy Reference

::: warning Legacy-era reference
This page preserves the complete ordinary-player profession and bench material from the older VAM
guide. It is not proof that an unlock level, worker restriction, recipe, or station still behaves the
same in Enhanced. The current [WoV Profession hub](./wov-professions-hub.md) and live recipe panels
take precedence.
:::

## How profession progress worked

The guide described five profession sections available from the WoV menu. Progress came from using,
wearing, crafting, harvesting with, or fighting with the related item type. A recipe required both
its listed character level and profession level; once both were met, selecting it in the Profession
tab learned the knowledge.

| Profession activity | Legacy progress action |
| --- | --- |
| Weapon recipe | Fight with the related weapon type. |
| Armor section | Wear the related armor type. |
| Weaponsmith | Craft weapons. |
| Armorsmith | Craft armor. |
| Headhunter | Defeat human enemies. |
| Tool recipe | Harvest with the related tool type. |
| Toolsmith | Craft tools. |
| Animal Breeder | Travel with a pet and let it defeat enemies. |

Attribute investment affected the profession multiplier shown at the bottom of the old interface.
The current Enhanced hub is the authority for any multiplier that still exists.

## Bench rules in the older guide

- WoV benches combined several similar base-game stations into one place.
- Advanced versions were crafted from the already placed basic bench, upgrading it in place.
- WoV recipes received the station's strongest cost reduction on WoV benches.
- The guide recommended WoV workers for specialized stations. Some compatible AoC workers were
  accepted, while ordinary base-game workers did not fit every WoV bench.
- Old unlock names and levels below are historical. Do not plan a current build around them until
  the Enhanced Profession tab shows the same requirement.

## Current Enhanced path

Open the current hub, choose **Profession**, and use the recipe requirements shown there. The
current Enhanced release confirms the Profession system and WoV benches as systems, but does not
independently confirm every old level, worker, multiplier, or station recipe above.
