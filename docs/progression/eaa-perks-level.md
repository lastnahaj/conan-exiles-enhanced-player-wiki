# EAA — Enhanced Perks & Level

**Source mod:** [Enhanced] EAA - Enhanced Perks & Level (`3720326124`)

![Official Workshop image for EAA - Enhanced Perks & Level](/media/mods/eaa-perks-level.png)

EAA extends the base progression model without changing the original perks. Wings Of Valhalla also
supplies a level system, so the Welcome Screen and Attributes panel show which combined values are
actually active. The complete standalone EAA progression documented by the mod is below.

## Standalone progression table

| Progression rule | EAA value |
| --- | ---: |
| Maximum character level | 300 |
| Total attribute points at level 300 | 120 |
| Maximum investment in one attribute | 30 |
| New perk milestone | 25 points in an attribute |
| Choice perk milestone | 30 points in an attribute |
| New perks across all attributes | 18 |
| Knowledge points by level 300 | More than 10,000 |
| Total experience from level 1 to 300 | 2,130,000,000 |

## Attribute-point schedule

- Levels **1–60** grant one attribute point per level.
- After level 60, an attribute point is awarded every four or five levels according to EAA's fixed
  schedule.
- Each attribute can be raised to 30.
- Reaching 25 unlocks that attribute's additional perk.
- Reaching 30 presents a choice between two final perks.
- Base-game perks remain unchanged.

EAA's experience curve, attribute awards, and knowledge-point values are fixed by the mod.
Experience gained in play advances the character through that fixed curve.
