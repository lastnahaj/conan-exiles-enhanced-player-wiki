# Wings Of Valhalla

**Source mods:** Wings Of Valhalla (Beta) (`3719965485`) and Wings Of Valhalla Equipment (Beta)
(`3721036709`)

![Official Workshop image for Wings Of Valhalla](/media/mods/wings-of-valhalla.png)

Wings Of Valhalla is a multi-system overhaul for character progression, professions, rewards,
bounties, equipment, companions, storage, resources, and custom world areas. Its equipment module
adds the companion weapon and armor assets used by the main mod.

## Welcome screen and hub

The Welcome Screen presents the server name, current maximum player level, and quick information on
entry. The WoV hub then brings five player systems into one interface:

| Tab | Purpose |
| --- | --- |
| **Profession** | Displays five profession categories, their experience, and their recipe unlocks. |
| **Rewards** | Shows milestone rewards on the character-level ladder. |
| **Bounty** | Tracks targets drawn from the base game and Wings Of Valhalla. |
| **Currency** | Displays the WoV currency interface. |
| **Settings** | Holds the player's WoV interface choices. |

## Character and follower progression

The current Enhanced build supports a custom character curve with a maximum level between 60 and
600. Milestone rewards and profession unlocks rescale to the selected cap. The value shown on the
Welcome Screen is the one in use.

Follower progression extends to level 100 in the WoV system, with an additional perk every ten
levels. See [WoV companions](../followers/wov-companions.md) for the current breeding loops.

## World areas

The current build includes a **Player Market**, **Portal Room**, and **Resource Mines**. The mines
contain the fifteen documented WoV resource types. Use the local
[storage and resources guide](../crafting/wov-storage-resources.md) for the associated tool and
sorting workflows.

## Edition and roadmap boundary

The older VAM guide documents the mod's Legacy-era systems. Its still-relevant player workflows
are included in the local pages above and explicitly labeled where the current Enhanced Workshop
page does not independently confirm an old detail. Old item statistics, locations, probabilities,
and unavailable acquisition routes are not treated as current Enhanced facts.

The public roadmap describes future development, not current server content. Planned systems are
therefore excluded from player instructions until a current Enhanced release documents them.
