# WoV Professions, Rewards, and Hub

Open the Wings Of Valhalla hub and choose **Profession**, **Rewards**, **Bounty**, **Currency**, or
**Settings**. The Welcome Screen shows the current character cap before you begin using the hub.

## Profession progression

WoV has five profession categories tied to the five core character attributes. Profession
experience comes from gameplay. The Profession tab shows each category, its progress, and the
recipes it can unlock.

The Legacy-era guide describes this recipe flow:

1. Perform the activity associated with the profession to gain profession experience.
2. Meet both the listed **character level** and **profession level** requirements.
3. Select the recipe in the Profession interface to add its knowledge.

Attribute investment can influence the displayed profession multiplier. Check the current hub for
the category and multiplier applied to your build.

### Legacy-era activity reference

The following activity map comes from Kaali's older VAM guide. It is included as a local reference
for the same profession concept; use the current Enhanced Profession tab when its labels differ.

| Older guide category | Documented activity |
| --- | --- |
| Weapon recipes | Use the related weapon type. |
| Armor sections | Wear the related armor type. |
| Weaponsmith | Craft weapons. |
| Armorsmith | Craft armor. |
| Headhunter | Defeat human enemies. |
| Tool recipes | Harvest materials with the related tool type. |
| Toolsmith | Craft tools. |
| Animal Breeder | Travel with a pet and let it defeat enemies. |

Profession unlocks include WoV benches and weapon arsenals. The exact requirement for each unlock
is displayed beside the recipe in the Enhanced hub.

## Level rewards

The **Rewards** tab shows the milestone ladder. The ladder rescales with the configured maximum
character level, so use the milestones displayed in the hub rather than an older fixed-level list.

## Bounties

The **Bounty** tab tracks eligible base-game and WoV targets. Use it to select or review the current
target and its progress. Bounty-related loot has a dedicated destination in the WoV sorting system;
see [Storage and resources](../crafting/wov-storage-resources.md).

## Currency and settings

The **Currency** tab displays WoV currency information. The **Settings** tab contains the ordinary
player choices for the hub and its interface.
