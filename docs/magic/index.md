Domain's Magic adds six schools with different resource, timing, and support roles. Start with the casting controls, then choose a school whose loop you want to learn.

## First casting session

1. Learn the relevant knowledge under **Sorcery → Domain's Magic**.
2. Place a spell item on the hotbar.
3. Read its full description for timing, cooldown, and targeting.
4. Practice the basic spell before adding traps, detonations, or an ultimate.
5. Use the school guide to understand what you build, consume, or trigger.

The [complete spell guide](./domain-magic.md) contains all thirty spells across Ember, Arctic, Umbra, Radiant, Voltaic, and Sanguine. Numerical values there are published mod defaults; the spell's current item description shows its effective behavior.
