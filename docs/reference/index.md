## Read the evidence label

A server observation records a visible example. Mod documentation describes published capabilities. A Legacy reference preserves older material. None of those labels should be read as a promise that every configurable value is active on the server.

## Suggest a correction

Use **Report a correction** at the bottom of a guide. Include the page, the value or step that changed, and what you observed in the current game interface. **Page history** shows the published revisions.
