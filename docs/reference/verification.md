# Verification

The evidence label above a guide explains what its information establishes. It is useful when comparing a published mod feature with the value or option currently shown in game.

## Guide labels

| Label | How to read it |
| --- | --- |
| **Mod documented** | The mod's public documentation describes the system. Configurable availability and tuning may differ on the server. |
| **Server observed example** | An owner-supplied capture records the visible example. It does not establish identical values for every spawn or item. |
| **Legacy reference** | The page preserves older documentation. Its values, routes, and screenshots are historical unless separately confirmed for Enhanced. |
| **Server information** | The page contains supplied server identity or reference/navigation information. |

The **Checked** date records the evidence review associated with that page. It is not a claim that the game was tested again on every publication date.

## When values differ

1. Check whether the guide labels the number as a published default or a captured example.
2. Read the current item, recipe, follower panel, or player interface.
3. Check the edition label before using an archived table.
4. Report a changed value through the correction link at the bottom of the guide.

The server's 5x identity alone does not establish stack limits, item prices, breeding odds, or every configurable multiplier.

## Images and credits

Mod illustrations come from the exact Enhanced Workshop page or approved author documentation. General Enhanced artwork comes from the official publisher page. Owner-supplied stat captures are identified as server observations.

Legacy screenshots retain an edition caption. Decorative artwork illustrates a topic; it does not prove a server location, spawn, drop, or configuration.

Each locally stored image has a provenance record. The [Source Library](./source-library.md) provides the source and credit trail.
