# Verification

The wiki separates what a mod publicly documents from what has been confirmed on this specific
server.

| Status                       | Meaning                                                                                                  |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- |
| Verified                     | The published claim has a first-party source, or a server fact has been confirmed and recorded.          |
| Server verification required | The mod capability is sourced, but effective server availability or tuning still needs live observation. |
| Draft                        | The entry is incomplete and is not eligible for publication as fact.                                     |

## Publication rules

- A server-specific factual entry needs at least one source URL and a verification date.
- Configurable behavior is not presented as the server's active behavior without observation.
- Legacy documentation or imagery never stands in for current Enhanced behavior.
- Images are local only when their first-party provenance and factual alt text are recorded.
- A missing image produces a text-only page, not substitute artwork.

Every locally stored image comes from an exact Enhanced Workshop page or another approved
first-party source and has a direct asset URL, source page, credit, retrieval date, mod identity,
and factual alt text in the image registry.

See the [source library](./source-library.md) for the audit date, first-party links, edition scope,
and the role each source is allowed to play.
