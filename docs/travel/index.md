# Travel & Exploration

Separate navigation aids from travel destinations: a marker helps you find a place; a travel system controls where it can send you.

## Choose a travel tool

| Goal | Guide | What to inspect |
| --- | --- | --- |
| Set a personal destination marker | [Simple Minimap](../qol/simple-minimap.md#custom-markers) | Marker label, storage choice, and clan sharing. |
| Understand compact maproom travel | [Mystical Travel Shelf](./mystical-travel-shelf.md) | Cartographer progression and aiming-based destination selection. |
| Understand WoV public areas | [WoV player areas](../crafting/wov-storage-resources.md#player-areas) | Player Market, Portal Room, and Resource Mines. |
| Review older mine and meteor systems | [Legacy world reference](./wov-world-reference.md) | Historical access, mine layers, and meteor guidance. |

## Prepare your navigation

1. Read the travel system's progression and interaction requirements.
2. Inspect the destinations actually offered in the installed interface.
3. Use labeled map markers for routes you want to revisit.
4. Review a marker's sharing choice before making it visible to clan members.

A map marker does not establish that its location is safe, public, or reachable. Portal Room destinations are the destinations currently presented by the server, rather than a fixed list reconstructed from older documentation.
