# Extended Thrall Stats

Extended Thrall Stats adds information to the normal follower and pet stat panel.
It extends the existing interface rather than replacing it.

## Inspect a follower

1. Open the follower's normal stats panel.
2. Allow a short delay for the additional fields to appear.
3. Read the melee and ranged multipliers alongside the current attributes.
4. Use the language toggle if you prefer English field names.

## Read the extra fields

| Field | What to compare |
| --- | --- |
| Melee damage multiplier | The follower's displayed melee scaling. |
| Ranged damage multiplier | Its displayed ranged scaling. |
| Damage percentage per attribute point | The damage bonus associated with an additional relevant attribute point. |
| Health per Vitality | The health contribution associated with Vitality. |
| Original follower name | The original identity behind a renamed follower. |

A multiplier, a per-attribute bonus, and a current attribute total describe different parts of
the follower. Compare like-for-like fields when evaluating two candidates.

## Use the values in a comparison

The [Valkyrie stat guide](./wov-valkyrie-stats.md) separates captured starting attributes,
growth chances, bonuses, and total health. Use the same distinction when inspecting your own
followers.
