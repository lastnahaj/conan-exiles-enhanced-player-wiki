# Followers

Choose a follower, understand its stats, then set up the commands and interface you will use in play.

## Start with your goal

| Goal | Guide | Key distinction |
| --- | --- | --- |
| Compare Valkyrie examples | [Valkyrie stats by location](./wov-valkyrie-stats.md) | Captured level-zero examples are not guaranteed values for every spawn. |
| Read a follower's multipliers | [Extended Thrall Stats](./extended-thrall-stats.md) | Damage multipliers, attribute bonuses, and totals are different fields. |
| Command a group | [Better Thralls](./better-thralls.md) | Follower limits and compatible groups still apply. |
| Move through owned followers | [Follower Collision](./follower-collision.md) | Personal movement changes; follower combat remains intact. |
| Breed Rocknoses or Dragons | [WoV companions](./wov-companions.md) | Use the current breeding station and outcome preview. |
| Inspect a pet, mount, or saddle | [Highmane companions](../combat/highmanes/companions.md) | Confirm companion type and saddle compatibility. |

## Put the systems together

1. Inspect the follower's level, attributes, and growth chances.
2. Read additional multipliers in the expanded stat panel.
3. Ask the follower to follow using the normal Follow action.
4. Use Warcry for the available group commands.
5. Adjust collision settings if owned followers obstruct movement.

If another follower refuses to join, check [follower groups and limits](./better-thralls.md#troubleshooting) before treating it as an interface failure.
